logbo BLE 設定

未接続

このブラウザは Web Bluetooth に対応していません。Android または PC の Chrome / Edge で、HTTPS のページとして開いてください（iPhone の Safari は非対応です）。

logbo の電源が入っていれば、いつでも「接続」から BLE で見つかります（同時に 3 台まで繋げます）。接続時に OS がペアリングの確認を出したら許可してください（暗号化した接続で Wi-Fi のパスワードを送ります。登録は残りません）。

SD カードの記録

本体の B ボタン長押しと同じです。止めると「SAFE」になってからカードを抜けます。

Wi-Fi 接続先

最大 8 件まで登録でき、優先度の大きい順に試して、つながらなければ次へ切り替えます（1 件あたり最長 30 秒）。2.4 GHz のネットワークだけ使えます。同じ SSID を保存すると上書きします。本体に保存されます（書き込み直しても残ります）。

  • —

無線（AP / STA）

保存すると次の起動から有効です。AP は本体が出す Wi-Fi（スマホや PC から直接つなぐ用）、STA は上の接続先につなぐ機能です。両方オフにすると Wi-Fi は止まり、BLE（このページ）だけになります。

地磁気キャリブレーション

台座の磁石によるずれを測ります。「開始」を押したら、本体をゆっくりあらゆる向きに回してください（裏返しも）。机・PC・車体など鉄や磁石から離れた場所で。3 本のバーがそろって十分たまると本体が自動で終わります。途中で「終了」を押しても構いません。
